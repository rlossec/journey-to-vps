# Record A (`readresolve.tech`)

**But :** lire l’IPv4 publiée dans la zone (via le résolveur local, donc **avec cache** possible).

```bash
dig A readresolve.tech
```

## Sortie attendue

```
;; flags: qr rd ra …; QUERY: 1, ANSWER: 1, …
;; QUESTION SECTION:
;readresolve.tech.              IN      A

;; ANSWER SECTION:
readresolve.tech.       3600    IN      A       54.36.100.9
```

## Lignes importantes

| Fragment | Lecture |
| --- | --- |
| `A 54.36.100.9` | Apex du domaine → IP du VPS. |
| `TTL 3600` (ou plus bas) | TTL **configuré** = 3600 ; une valeur plus basse = **reste** en cache. |
